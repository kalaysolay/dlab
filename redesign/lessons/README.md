# Кликабельный макет экрана урока

Основной результат — `index.html`. Макет повторяет визуальный язык текущего
кабинета ученика и показывает длинную лекцию как главную часть урока.

Что можно проверить:

- переключение вкладок «Теория» / «Тестирование»;
- переключатель sticky / non-sticky для вкладок в правом нижнем углу;
- содержание длинной лекции и переходы к разделам;
- крупные формулы и пошаговый пример;
- изображения внутри текста и просмотр в модальном окне;
- места для встроенного видео и GIF-анимации;
- выбор ответов, переходы по номерам вопросов и кнопки «Назад» / «Дальше».
- переключатель сценария «с тестом / без теста»;
- состояние «Остались вопросы» при попытке завершить тест с пропусками;
- состояние «Тест завершён» только после ответа на все вопросы.
- интерактивные примеры вопросов MCQ, FILL IN и MATCH;
- отдельный финальный блок для урока без тестирования с кнопкой «Завершить урок».

Прогресс урока и ручное сохранение места намеренно убраны до следующего этапа.

Макет можно открыть через общий сервер редизайна:

```powershell
node ..\server.cjs
```

После запуска: `http://localhost:4173/lessons/`.

## Ранние визуальные концепты

В папке лежат три визуальных направления редизайна экрана урока:

- `variant-1.png` — один вариант в двух состояниях: вкладки закреплены под шапкой и вкладки остаются в потоке страницы.
- `variant-2.png` — спокойный одноколоночный учебный лист.
- `variant-3.png` — двухколоночная учебная рабочая область.

Во всех макетах:

- есть вкладки «Теория» и «Тестирование»;
- отсутствует отдельный переключатель RU / KK внутри урока;
- тест показывает один вопрос за раз;
- номера вопросов находятся над кнопками «Назад» и «Дальше»;
- отвеченные вопросы отмечены зелёным, текущий и неотвеченные — синим.
