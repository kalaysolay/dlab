# Самостоятельная викторина ученика

Актуальный вход: `/student/quiz` → «Создать викторину», форма `/student/quiz/create`.
Она использует существующие опубликованные вопросы Damulab по предмету и классу,
а не отдельную БД или скрытую игру каталога.

- Предмет и класс выбираются из доступного банка.
- Язык изначально совпадает с текущим языком сайта, его можно изменить.
- По умолчанию 15 вопросов и 10 секунд на раунд; диапазоны 1–50 и 5–120.
- Комната рассчитана максимум на 4 игроков, отдельного поля количества игроков нет.
- Если вопросов меньше запрошенного, форма показывает доступное количество;
  сервер повторно проверяет банк при создании и старте.
- Можно играть одному либо пригласить гостей кодом. Выбранный класс определяет
  вопросы, класс профиля гостя не ограничивает участие.

Самостоятельные и каталожные игры используют один QuizRoomService, фабрику снимков,
таймер, API и экран комнаты. Старые QuizService, DTO и UI исключены из приложения.
Контракты предыдущего бинарника оставлены только в тестовых исходниках для ручных
проверок старого артефакта. Переключатель game-catalog-enabled удалён.

## Обновление существующей базы

Перед запуском новой сборки сохраните резервную копию и завершите активные игры
предыдущей версии. Flyway V56 остановит обновление при активной старой предметной
комнате: её ответы не имеют необходимых снимков/времени и не реконструируются.
Старые ожидающие лобби становятся EXPIRED; исходные раунды и участники не удаляются.
Завершённые ответы и результаты остаются без пересчёта и доступны по прежним ссылкам.
Исторический рейтинг показывает сохранённый максимальный балл, время — неизвестное.

Нужен перезапуск приложения с новой сборкой, обновления страницы недостаточно.
Если используется scripts/quiz-preview.ps1, стенд запускает закреплённый JAR из
своего state.json: обычный Start не подменяет его файлом из build/libs.
Рабочая база, порты и запущенные приложения при этой доработке не переключались.

## Проверки

Gradle wrapper: build и i18nVerify. Для ограниченного heap можно добавить
`-I scripts/quiz-foundation-test.init.gradle`.
Тесты формы и общего движка: QuizArenaIntegrationTest, QuizStudentUiIntegrationTest;
миграции/история: QuizFoundationMigrationTest, QuizFoundationUpgradeStartupTest,
QuizCompatibilityIntegrationTest.

DOM-проверки: `node --test scripts/quiz-game-ui.test.cjs scripts/quiz-game-dom.test.cjs scripts/quiz-create-dom.test.cjs`.
PostgreSQL-проверки запускаются с QUIZ_TEST_DB_* исключительно в новых выделенных
схемах; рабочие данные и существующие схемы не очищаются.
