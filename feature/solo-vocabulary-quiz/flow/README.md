# Каталог игр и универсальная комната

Стартовая страница: `index.html`. Макет полностью статический, сервер Node.js не нужен.

Требования для реализации, включая отличия от ранних макетов, зафиксированы в [SPECIFICATION.md](../SPECIFICATION.md).

## Основной маршрут

`Игры → готовая карточка игры → предыгровая комната → начать игру`.

Ребёнок не выбирает режим «один» или «с друзьями». Любая игра создаёт комнату минимум для одного участника. Приглашение друзей остаётся необязательным действием на экране запуска.

## Кликабельные страницы

- `index.html` — каталог готовых игр и вход по коду.
- `room.html?game=english` — слова на английском; класс не выбирается на экране, но может использоваться для безопасной выборки.
- `room.html?game=kazakh` — слова на казахском; класс не выбирается на экране, но может использоваться для безопасной выборки.
- `room.html?game=math` — математика; класс берётся из профиля и может быть изменён.
- `room.html?game=facts` — «Верю / не верю»; класс не используется.
- `join.html` — короткий вход приглашённого игрока по коду.
- `room.html?game=english&mode=guest&code=QZ7K2M` — состояние гостя, который ждёт организатора.
- `word-game.html`, `subject-game.html`, `true-false-game.html` — три игровые механики.
- `result.html` — результат игры.
- `states.html` — индекс ключевых сценариев и пограничных состояний.

## Администрирование

- `admin-quizzes.html` — список игр, фильтры, статусы и готовность контента.
- `admin-quiz-edit.html` — карточка игры, локализации, политика класса и правила комнаты.
- `admin-quiz-content.html` — выбор банка и безопасные правила отбора контента.
- `admin-quiz-publish.html` — проверка готовности, ученический предпросмотр и публикация.
- `admin-word-bank.html` — банк слов с аудиторией, источником и статусом модерации.
- `admin-word-edit.html` — слово, допустимые переводы, классы и источник.

Выбор класса в комнате и безопасная аудитория контента задаются раздельно. Минимум участников равен одному, поэтому одиночная и совместная игра используют один и тот же жизненный цикл комнаты.

Все страницы используют существующие `app.css`, `fonts.css` и `lucide-sprite.svg`, поэтому визуальные решения можно перенести в текущие шаблоны без создания отдельной дизайн-системы.
