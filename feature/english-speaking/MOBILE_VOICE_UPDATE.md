# Обратная связь с телефона: 4 ноября 2026

После проверки владельцем изменено поведение озвучки и расшифровки.

- Новая первая реплика и принятый ответ собеседника озвучиваются автоматически. TTS получает вступление/реакцию и вопрос из серверных данных, без текста ученика и цитат исправлений. Лимит полного текста — 1000 символов; прежние ограничения ответа, времени и бюджета сохраняются.
- Есть выключатель «Автоозвучка» для текущей страницы. «Послушать» и «Помедленнее» воспроизводят ту же полную реплику. История при открытии, помощь и раскрытие исправлений не запускают новую озвучку. Уход в фон останавливает звук; позднее аудио не включается в фоне.
- Браузер может запретить autoplay после асинхронного запроса. В этом случае показывается предложение нажать «Послушать»; запись не запускается сама. Один переиспользуемый плеер сохраняет разрешение после ручного воспроизведения. Физические Safari/Chrome ещё требуют проверки.
- После ASR поле доступно для правки, но focus() не вызывается. Клавиатура открывается по нажатию на поле. Явный выбор «Ответить текстом» по-прежнему фокусирует ввод.

## Корректность исправлений

`I want to buy some juice` означает «Я хочу купить сок»; `I may buy some tea` — «Возможно, я куплю чай». Обе фразы грамматически допустимы; разница в намерении, исправлять их как ошибки нельзя. Промпт и классификация навыков из-за этих примеров не менялись.

На живом локальном DeepSeek проверены четыре синтетических ответа в ситуации holiday_plans/B1: `I am planning to go to the market`, `I want to buy some juice`, `I may buy some tea` — без замечаний; `I want buy some apples` — исправлено `want buy → want to buy`, skill=grammar.verb_patterns, отдельное наблюдение confirmed.

В IAB на Windows, 390 px, загружен синтетический MP3: после ASR activeElement=BODY, textarea видима и редактируема, горизонтального переполнения нет. Подтверждение ответа автоматически вызвало один успешный TTS-запрос без нажатия «Послушать». Это не проверка физической экранной клавиатуры Android/iOS. Артефакты — игнорируемый build/qa/speaking.

Интеграционные регрессии проверяют полное вступление/вопрос, реакцию/вопрос принятого хода, повторное использование аудио и отсутствие произвольного клиентского текста/учебных цитат в TTS. Синтаксис speaking.js проверен Node. Полную сборку следует запускать без одновременного processResources другого Gradle-процесса: обновление ресурсов работающим preview во время тестов может временно убрать Thymeleaf-шаблон.

Финальная полная `gradlew.bat build i18nVerify`: 526 тестов без падений/ошибок/пропусков, 551 ключ ru/kk. Первый прогон столкнулся с временно отсутствующим lecture-form при параллельном обновлении ресурсов preview; после завершения обновления полный прогон прошёл. Код уроков не менялся.
