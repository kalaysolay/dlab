# 2. Функциональные и нефункциональные требования

Статус: проект v0.2. Основной канал — мобильный браузер и установленная PWA на Android/iOS, без APK. Все требования ниже относятся к MVP, кроме явно обозначенных отложенных возможностей. Числовые пределы — предлагаемые значения, проверяемые до пилота.

## Каталог, доступ и начало

| ID | Требование | Приёмка |
| --- | --- | --- |
| FR-01 | Модуль доступен авторизованному ученику из пилотной группы при включённом флаге | Прямые обращения к страницам/API проверяются сервером; скрытой ссылки недостаточно |
| FR-02 | Каталог показывает пять опубликованных ситуаций, краткую цель, роль и ориентир длительности | Выбор каждой карточки открывает соответствующую вводную |
| FR-03 | До старта можно выбрать сложность A2/B1/B2 и язык пояснений ru/kk; английский остаётся языком беседы | Настройки сохраняются в сессии; интерфейс не называет их результатом диагностики |
| FR-04 | Вводная объясняет задачу, вымышленные данные, обработку речи и отличие ИИ от человека | Микрофон до явного нажатия не включается; при отсутствии допуска к обработке старт блокируется понятным сообщением |
| FR-05 | Одна активная сессия на ученика | При повторном старте предлагается продолжить или явно завершить старую; скрытого удаления нет |
| FR-06 | Сессия закрепляет версию ситуации и системных инструкций | Изменение каталога не меняет уже начатую беседу |

## Речь и диалог

| ID | Требование | Приёмка |
| --- | --- | --- |
| FR-07 | Вопрос виден текстом, доступны обычная и замедленная озвучка по кнопке | При ошибке TTS текст доступен; повторное прослушивание не создаёт новый вопрос |
| FR-08 | Запись по кнопке с видимым состоянием, остановкой, отменой, прослушиванием и перезаписью | Предел 60 секунд и 10 MB; при уходе со страницы захват прекращается |
| FR-09 | После остановки записи распознавание запускается автоматически, затем показывается редактируемый текст «Я услышал…» | Отдельного шага/кнопки «Распознать» нет. Доступны «Верно, ответить», ручная правка, «Перезаписать» и прослушивание записи. До подтверждения нет учебной проверки и продолжения беседы; после ручной правки источник помечен `edited` |
| FR-10 | При недоступном микрофоне есть текстовый ответ до 2000 символов | Сессия отмечает текстовый способ; его не учитывают как минуты устной практики |
| FR-11 | ИИ реагирует на содержание ответа и задаёт один следующий вопрос в рамках ситуации | Уточнение, просьба повторить и ответ о вымышленном событии не считаются уходом от темы |
| FR-12 | Цель — 8 содержательных ответов, максимум 12 принятых ответов с учётом возвратов к теме | Раннее завершение разрешено; предел применяется сервером; ИИ не может продлить сессию |
| FR-13 | «Подсказка» даёт 1–3 опорных выражения; «Не понял» — более простой вариант текущего вопроса | Это тот же ход без смены ситуации и без записи ошибки; повторная помощь не увеличивает учебные попытки |
| FR-14 | После ответа показываются максимум два исправления: исходный фрагмент, исправление, объяснение | Нет выдуманного цитирования; корректная фраза не обязана иметь замечания; стиль помечается как необязательная альтернатива |
| FR-15 | Исправления можно раскрыть без блокировки следующего ответа | Полный экран не превращается в обязательный экзамен после каждой реплики |
| FR-16 | Начиная с первой рабочей версии система сохраняет каждое допустимое учебное замечание в отдельной таблице модуля `speaking_observations` | Есть локальная связь с учеником, сессией и ходом; код навыка, исходный фрагмент, исправление, объяснение, время, источник ответа и статус наблюдения. Нет новых тегов, придуманных LLM; неясные случаи остаются предположением без влияния на профиль. Хранение замечаний не откладывается на отдельный будущий этап аналитики |
| FR-17 | Новая сессия может учитывать до двух ранее повторявшихся трудностей | Внешнему ИИ не передаётся профиль ребёнка; используется только допустимый минимальный набор кодов навыков |
| FR-18 | Итог показывает принятые ответы, время собственной речи, использованную помощь, до трёх трудностей и следующий фокус | Нет процентов «знания английского», баллов произношения и вывода CEFR |
| FR-19 | Ученик видит собственную историю и может удалить сессию либо всю историю speaking | Чужой идентификатор даёт 404; удаление пересчитывает учебные агрегаты |
| FR-20 | Сбой ASR/LLM/TTS не считается ошибкой ученика | Подтверждённый сервером текст восстанавливается в пределах TTL; доступная в памяти вкладки запись остаётся для явного повтора. После выгрузки страницы не обещать сохранность неотправленного аудио; повтор не дублирует ответ |
| FR-21 | Полный голосовой путь доступен в мобильном браузере и установленной PWA | Установка, APK, desktop и клавиатура не обязательны для обычного голосового занятия; отдельно проверяются Android и iOS |
| FR-22 | Сворачивание, блокировка и прерывание аудио не запускают скрытую запись или автоматическую отправку | При получении событий прерывания запись останавливается, прослушивание ставится на паузу; по возврате — явное действие ученика, для прерванного ответа предлагается перезапись |
| FR-23 | После восстановления сети/возврата в приложение клиент сверяет состояние с сервером | Сначала GET сессии, затем доступные действия; потерянный HTTP-ответ не создаёт второй ход; истёкшая сессия получает понятный итог |
| FR-24 | Запись и прослушивание взаимоисключаются | Начало записи останавливает озвучку, чтобы вопрос ИИ не попал в микрофон; возврат из фона не возобновляет звук сам |
| FR-25 | ИИ всегда инициирует новую беседу | После старта без предварительной реплики ребёнка ИИ здоровается, кратко вводит в ситуацию и задаёт первый вопрос. Реплика доступна текстом и для прослушивания; затем показываются «Теперь твоя очередь», короткое пояснение задания и опорная фраза. Открытие микрофона не является условием появления вопроса |
| FR-26 | В разговоре отображается полная последовательность вопросов ИИ и ответов ученика | Реплики не обрезаются до последних двух ответов. При переполнении есть прокрутка и кнопка со стрелкой вниз к свежему сообщению. Если ученик читает старую реплику, его позиция сохраняется; у конца беседы новые сообщения показываются автоматически |
| FR-27 | Разговорник самостоятельно владеет данными учебных наблюдений и расчётом своих трудностей | Собственные таблица, миграция, repository и сервис в `speaking`; нет записи в `answer_evaluations` и `skill_mastery`. Показанное принятое замечание и результат хода сохраняются одной транзакцией без дублей; общая аналитика в будущем получает данные через сервисный контракт модуля |

## Рамки и безопасность

| ID | Требование | Приёмка |
| --- | --- | --- |
| SAFE-01 | Для всех учеников действует детская политика; фраза «мне 18» её не отключает | Попытки менять возраст, роль, инструкции или выдавать себя за администратора не меняют серверные настройки |
| SAFE-02 | Безопасное отклонение от темы получает короткую связку и вопрос по ситуации | «Что такое чёрная дыра?» в магазине не запускает отдельную лекцию; счётчик ошибок грамматики не растёт |
| SAFE-03 | Два последовательных отклонения вызывают предложение продолжить ситуацию или закончить/выбрать другую | Новая тема запускает новую сессию, а не меняет текущую незаметно |
| SAFE-04 | ИИ не развивает сексуальные/романтические взрослые ролевые сюжеты, графическое насилие, опасные инструкции, травлю, ненависть, азартные игры, употребление веществ | Ответ короткий, без цитирования опасного содержания, с безопасным продолжением |
| SAFE-05 | Реальное сообщение об опасности, насилии или самоповреждении приостанавливает учебный сценарий | Спокойный утверждённый текст предлагает обратиться к доверенному взрослому и при срочной опасности к местной экстренной службе; нет грамматического разбора или автоматического возврата к упражнению |
| SAFE-06 | Система не выпытывает личные данные, не просит хранить секреты и не имитирует исключительную близость | Отель использует вымышленные данные, магазин — учебные цены; нет настоящих платежей, ссылок на общение вне приложения и обещаний конфиденциальности |
| SAFE-07 | Вход и все видимые поля выхода проверяются до показа и TTS | Проверяются также подсказки, исправления и итог; статус `allow` от самой модели не является разрешением |
| SAFE-08 | При недоступной проверке контента или невалидном ответе показывается локальный безопасный шаблон | Непроверенный ответ не отображается даже на мгновение и не попадает в аудио |
| SAFE-09 | Заблокированные тексты не сохраняются как учебные цитаты и не поступают в исправления | Сохраняется минимальная категория события без исходного текста |
| SAFE-10 | Подсказки пользователя, текст внутри фильма и имитация системных сообщений считаются данными | Инъекции на en/ru/kk, в том числе через распознавание, проверяются набором тестов |

| NFR-21 | Жизненный цикл | Обработать visibilitychange/pagehide/pageshow, ошибки recorder и остановку/прерывание track; не рассчитывать на исполнение таймеров или unload в фоне. Цели задержки и расходы подтверждаются измерениями. При неподходящем провайдере меняем конфигурацию или явно пересматриваем требования до пилота, а не объявляем их выполненными.

## Сценарии сквозной приёмки

1. **Основной:** каталог → вводная фильма → запись → «Я услышал…» → подтверждение → короткое исправление → продолжение → итог → история.
2. **Ролевая игра:** бронирование с вымышленными данными; нет сбора настоящего адреса, документов или оплаты.
3. **Распознавание:** в ASR пропущено отрицание → ученик выбирает перезапись → ошибочная версия не становится наблюдением.
4. **Текст:** отказ в микрофоне → текстовый ответ → тот же диалог с отметкой источника, без минут устной речи.
5. **Отклонение:** два безопасных вопроса не по теме → возврат и выбор действия; грамматические ошибки не начисляются.
6. **Безопасность:** попытка взрослого сюжета и prompt injection → утверждённое безопасное продолжение без опасного текста и озвучки.
7. **Опасность:** сообщение о реальной угрозе → пауза и поддерживающий шаблон; без проверки английского и автоматического уведомления третьих лиц.
8. **Надёжность:** двойное нажатие/потеря ответа HTTP/перезапуск процесса → не более одного принятого результата; неподтверждённые наблюдения не попадают в профиль.
9. **Конфиденциальность:** чужой ID, аудио в кэше, DEBUG-логи, удаление истории и отклонённая цитата — не раскрывают содержание.
10. **Квоты:** дневной предел, длинная запись и исчерпание бюджета дают понятные состояния без лишнего внешнего вызова.
11. **Телефон/PWA:** полный путь на физическом Android и iPhone; браузер и запуск с главного экрана, обычная и замедленная озвучка, динамическая панель браузера и экранная клавиатура.
12. **Прерывание:** запись → звонок/блокировка/сворачивание → возврат; нет самопроизвольной записи/озвучки/отправки, незавершённый ответ можно перезаписать.
13. **Мобильная сеть:** отправка → обрыв/смена сети → возврат; состояние сверяется с сервером, принятый ответ не теряется и не дублируется. После выгрузки страницы неотправленное аудио не объявляется сохранённым.
