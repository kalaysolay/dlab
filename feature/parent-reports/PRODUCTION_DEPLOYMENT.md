## Telegram в production

Локальный poller остановлен. Секреты заданы только в защищённом окружении выпуска,
в Git не находятся. Тестовые привязки и дети из локального стенда не перенесены.
Настоящий родитель подключается кнопкой в https://damulab.kz/parent и нажимает
«Начать» в боте. Далее отправка по понедельникам в 09:00 по времени Казахстана,
если родитель не изменил расписание или не остановил рассылку.

Учёт посещений начинается с V76. Старые и частично покрытые недели без результатов
не трактуются как доказательство отсутствия входов: сообщение указывает отсутствие
полных данных о посещениях. После полной недели учёта различаются отсутствие
зафиксированных посещений и посещения без завершённых занятий.

## Управление выпуском

Секреты в compose-файлах каталога выпуска защищены правами доступа; не печатать их
в общий журнал и не переносить в репозиторий.

Повторный запуск текущего проверенного образа с Telegram:

```bash
cd /home/deploy/releases/parent-reports-0233206-20261110
docker compose --project-directory /opt/damulab --project-name damulab \
  -f compose-before.json -f telegram-override.json up -d --no-deps --no-build app
```

Для запуска того же образа с выключенным Telegram вместо `telegram-override.json`
использовать `deploy-override.json`. Для возврата к предыдущему образу —
`rollback-override.json`; совместимость прежнего приложения со схемой V76 проверена
на копии. При полном откате также снять webhook. Новые таблицы и накопленные
данные не удаляются. Backup и прежний образ сохранены в каталоге выпуска.
