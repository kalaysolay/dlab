# Подсказки для агентов и разработчиков

- Сборка: **Gradle** (`gradlew` / `gradlew.bat`), не Maven.
- Стиль: не усложнять код; предпочитать простые, понятные и устойчивые конструкции.
- Пайплайн генерации вопросов (скиллы `damulab-question-*`, `content/runs`) перенесён в репозиторий `kz-textboox-parser` — рядом с учебниками.

Подробные правила для Cursor: [.cursor/rules/damulab-conventions.mdc](.cursor/rules/damulab-conventions.mdc).
