# Подсказки для агентов и разработчиков

- Сборка: **Gradle** (`gradlew` / `gradlew.bat`), не Maven.
- Не усложняй реализацию, если без этого можно обойтись. Предпочитай простые, понятные и устойчивые решения, достаточные для текущей задачи.
- Не рефактори весь проект при реализации отдельной фичи, если этого явно не требуют. Ограничивай изменения кодом, необходимым для этой фичи.
- Пиши поясняющие комментарии к коду на русском. Сложные места объясняй прямо внутри метода рядом с логикой, а не только в Javadoc над методом.
- После реализации каждой фичи выполняй пробный билд через Gradle wrapper и необходимые проверки её работы. Исправляй обнаруженные ошибки до завершения задачи; в итоге сообщай результат проверок.
- После завершения задачи спроси, нужно ли закоммитить изменения, если пользователь ещё не дал указаний о коммите. Не спрашивай повторно при уже данном согласии или запрете; без явного разрешения не коммить и не пушь.
- Пайплайн генерации вопросов (скиллы `damulab-question-*`, `content/runs`) перенесён в репозиторий `kz-textboox-parser` — рядом с учебниками.

Подробные правила для Cursor: [.cursor/rules/damulab-conventions.mdc](.cursor/rules/damulab-conventions.mdc).
