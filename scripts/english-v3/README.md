# Новый набор английских викторин: 500 заданий

Готовая ручная поставка для существующего проекта Damulab и PostgreSQL со схемой после V59–V65. Это отдельные SQL-скрипты, **не автоматическая Flyway-миграция**. Рабочая БД при подготовке не изменялась.

## Что входит

- **350 отдельных английских слов (70%) и 150 выражений (30%)**, направление EN → RU.
- 10 тематических игр по 50 заданий. В каждой — 35 слов и 15 выражений.
- 100 узких смысловых групп по 5 заданий. Три неверных ответа берутся только из той же группы и имеют ту же часть речи.
- Отдельные запреты для пересекающихся значений: например, revenue / turnover. Синонимичный перевод не используется как заведомо неверный.
- Уточнение значения в английском вопросе только там, где без контекста многозначность мешает однозначному ответу.
- Четыре варианта ответа перемешиваются существующим движком. Для каждого задания есть минимум три допустимых неверных варианта.

Доли 70/30 относятся к **набору**, а не к каждому случайному запуску из 10 вопросов: действующий движок случайно выбирает задания из темы. Java-код и алгоритм выбора вопросов в этой поставке не меняются. Сложность `3` — внутренняя шкала проекта, не оценка CEFR.

## Файлы

| Файл | Назначение |
|---|---|
| `questions.tsv` | Все 500 вопросов, четыре варианта A–D и правильная буква. UTF-8, разделитель — табуляция. |
| `content.txt` | Редактируемый авторский исходник: тема, смысловая группа, слово/выражение, перевод и необязательный контекст. |
| `ambiguous-pairs.txt` | Пары с пересекающимся значением, запрещённые в качестве неверных ответов друг для друга. |
| `manifest.json` | Состав и точные количества. |
| `00_preview.sql` | Просмотр старых наборов, количества слов, комнат и сторонних игр, использующих эти банки. Только чтение. |
| `01_delete.sql` | Удаление **9 старых EN → RU** банков и их зависимостей. RU → EN остаётся. |
| `01_delete_all_english.sql` | Альтернатива: удаление **16 старых английских банков обоих направлений** и их зависимостей. |
| `02_load.sql` | Создание 10 опубликованных игр и банков v3, 500 заданий и матрицы запретов вариантов. |
| `03_verify.sql` | Проверка переводов, количества, публикаций, конфигураций и всей матрицы вариантов. Ошибка останавливает транзакцию. |
| `replace-en-ru.psql` | Атомарно: удалить старые EN → RU → загрузить 500 → проверить → COMMIT. |
| `replace-all-english.psql` | Та же атомарная замена, но с удалением старых английских банков обоих направлений. |
| `apply-prod.sh` | Готовый запуск для текущего Docker Compose prod: предпросмотр, остановка app, dump БД, атомарная замена и возврат app. |
| `generate.cjs`, `*.template.sql` | Воспроизводимая генерация SQL и TSV. |

TSV — пример допустимого расклада, а не жёстко заданный порядок ответов в игре. В нём правильный ответ находится в каждой позиции ровно 125 раз. При запуске игры движок самостоятельно выбирает варианты внутри разрешённой группы и перемешивает их.

Тексты и переводы составлены для этого набора. В `source_reference` указано авторское происхождение, без утверждения о внешней словарной проверке каждого задания.

## Область удаления

По умолчанию удаляются только явно перечисленные системные EN → RU банки: `basic-en-ru-400-v1` и восемь `english-<theme>-en-ru-v2`. В расширенном варианте к ним добавляются `basic-ru-en-300-v1` и шесть системных RU → EN банков v2.

**Физически удаляются также связанные старые комнаты, раунды, участники, ответы, результаты, ключи создания комнат, связи с классами, версии, переводы, запреты вариантов и редакционные/видимые события.** Это удаление истории соответствующих игр. Казахские банки, предметные викторины и пользовательские банки с другими кодами не входят в список удаления.

Скрипт откажет до удаления, если остались ACTIVE/WAITING комнаты выбранных игр или удаляемый банк используется сторонней конфигурацией игры. Сначала нужно завершить/отменить эти комнаты либо отдельно решить судьбу сторонней игры. Защитные проверки обходить не требуется.

Список определяется точными кодами, а не `LIKE 'english-%'`. Указатели на опубликованные и черновые версии обнуляются перед удалением версий, запреты чистятся по обоим направлениям связи. Если какая-либо неизвестная новой версии приложения внешняя связь не учтена, FK остановит транзакцию.

## Запуск на целевой БД

Для текущего production-деплоя проекта (`/opt/damulab`, `.env.prod`, `docker-compose.prod.yml`) достаточно скопировать эту папку в `/opt/damulab/scripts/english-v3` и выполнить **на сервере**:

```bash
cd /opt/damulab

# Только посмотреть состав удаления, без остановки app и без записи в БД.
sudo sh scripts/english-v3/apply-prod.sh --preview

# Заменить старые EN → RU; RU → EN сохранить.
sudo sh scripts/english-v3/apply-prod.sh

# Альтернатива предыдущей команде: убрать также старые RU → EN.
# sudo sh scripts/english-v3/apply-prod.sh --all-old-english
```

Production-скрипт сам использует `psql` из контейнера PostgreSQL; устанавливать клиент на сервер не нужно. Он останавливает только `app`, делает полный dump БД в `/var/backups/damulab/english-before-v3-*.dump`, проверяет читаемость архива, выполняет замену и возвращает `app` в прежнее состояние. При SQL-ошибке транзакция откатывается, а ранее работавшее приложение запускается со старым набором. Если `app` был остановлен до запуска, скрипт оставит его остановленным. Пересборка приложения для замены слов не требуется.

Если найдены ACTIVE/WAITING комнаты, скрипт откажет. Их надо закончить/отменить в приложении и повторить запуск. Не требуется вручную менять статусы в БД.

Ниже — альтернативный запуск SQL напрямую, если используется другая инфраструктура.

Понадобится `psql`. Перед заменой сделайте обычную резервную копию БД и остановите приложение на время выполнения. Параметры подключения задайте стандартными `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, а пароль — через `.pgpass` или `PGPASSWORD`.

Из корня репозитория:

```powershell
# Сначала посмотреть, что попадёт под удаление.
psql -X -v ON_ERROR_STOP=1 -f scripts/english-v3/00_preview.sql

# Вариант по умолчанию: заменить только EN → RU.
psql -X -f scripts/english-v3/replace-en-ru.psql

# АЛЬТЕРНАТИВА предыдущей команде: удалить старые английские банки обоих направлений.
# Новый набор в этом варианте также только EN → RU, 500 заданий.
# psql -X -f scripts/english-v3/replace-all-english.psql
```

Файл-обёртка включает `ON_ERROR_STOP`, общую транзакцию, ожидание блокировки не более 10 секунд и лимит каждого SQL-оператора 120 секунд. Вложенные файлы находятся относительно самой обёртки. Если загрузка или проверка упала, **удаление тоже откатится**. Не выполняйте обёртку с дополнительным `--single-transaction`: транзакция уже есть внутри.

После успешной замены можно независимо проверить набор:

```powershell
psql -X -v ON_ERROR_STOP=1 --single-transaction -f scripts/english-v3/03_verify.sql
```

Если нужны именно раздельные стадии, каждая запускается с `--single-transaction`. В этом случае между стадиями уже нет общего атомарного отката; для штатной замены используйте обёртку.

```powershell
psql -X -v ON_ERROR_STOP=1 --single-transaction -f scripts/english-v3/01_delete.sql
psql -X -v ON_ERROR_STOP=1 --single-transaction -f scripts/english-v3/02_load.sql
psql -X -v ON_ERROR_STOP=1 --single-transaction -f scripts/english-v3/03_verify.sql
```

Повторное удаление старого набора допустимо. Повторная загрузка v3 намеренно останавливается на проверке занятых кодов, чтобы не дублировать и не переписывать уже опубликованный контент. Скрипты не сбрасывают последовательности ID и не меняют `flyway_schema_history`.

## Изменение набора и проверки

После правок в `content.txt` / `ambiguous-pairs.txt`:

```powershell
node scripts/english-v3/generate.cjs
```

Генератор проверяет 500 уникальных вопросов, 350 слов / 150 выражений, по 35/15 в каждой теме, 100 пятёрок, отсутствие повторов ответов внутри группы и минимум три допустимых дистрактора у каждого вопроса.

Интеграционный тест выполняется **только на явно указанном PostgreSQL**, в случайной отдельной схеме:

```powershell
$env:ENGLISH_V3_TEST_DB_URL = 'jdbc:postgresql://localhost:55439/postgres'
$env:ENGLISH_V3_TEST_DB_USER = 'postgres'
$env:ENGLISH_V3_TEST_DB_PASSWORD = '<пароль тестовой БД>'
.\gradlew.bat test --tests kz.damulab.EnglishVocabularyV3PackageTest
```

Тест проверяет удаление с реальными FK и историей, защиту активных комнат и сторонних игр, полный откат удаления при конфликте загрузки, сохранность остальных банков, оба варианта удаления и повторные запуски. Все 500 заданий прогоняются через действующий `VocabularyRoundProvider` с четырьмя перемешиваниями каждого вопроса.
